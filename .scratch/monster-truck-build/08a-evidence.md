## Production and integration

Nine original modular GLBs are generated by `assets/scrapyard/source/build_scrapyard.py`, with an editable `scrapyard.blend` library: wreck, three-high wreck stack, scrap pile/panels/pipes, corrugated cargo container, corrugated fence, shutter workshop, industrial silo/conveyor skyline, compressed parking wreck and striped gate post. Blender 5.2.1 native generation exits 0 with `SCRAPYARD EXPORT PASS`. The source directory has `.gdignore`, so Godot imports portable GLBs without a Blender installation. The generator compiles successfully with Python 3.9; no external asset input or audio is used.

The kit is integrated in the actual TestArea around the retained cooperation exercise. A continuous visible fence bounds the apron at x ±36, z −38/+18. Reachable wreck stacks, containers and scrap have static triangle collision on layer 5 (walking world and truck contact). The workshop, industrial skyline and dense layered salvage stock are behind that fence with solid collision. Because roof riders can climb over the fence, four non-overlapping lower ground strips extend support outside the unchanged 80m apron to the visual 240m backdrop. There is no invisible boundary, new route exit, active machinery or hazard. No attempt, control, timer, handling or scoring code changes.

All four original gate and both original parking-wreck colliders retain their exact shapes/transforms; visible modules dress those shapes. Both bump colliders retain their dimensions, positions and tyre-ground layer. Their lit concrete and top seams replace flat unshaded appearance. The existing arrival sign gains solid player/truck-contact collision. The original 80m apron collider is unchanged. Its former unsupported edge is now supported by the lower exterior skirt; the human session procedure removes the obsolete nearby edge-fall trial and retains ordinary roof fall/reboarding and the existing side-bank overturn. No outer-edge-failure validation is claimed. Flush asphalt repairs/drains and surface aggregate cannot snag feet or change handling. Broad dust, fine grain, repaired seams and old tyre sweeps come from the shared ground shader. Warm directional sunlight and cool ambient fill replace flat unshaded daylight.

Every module has one joined mesh, 2–7 surfaces: gate 520 triangles, parking wreck 932, skyline 1,968, fence 3,024, scrap pile 3,048, wreck 3,052, stack 9,156, workshop 11,124 and container 9,396. Aggregate uses one 1,600-instance MultiMesh. Module origins are ground-centred metres, with Blender Z-up converted to Godot Y-up. Placement is reusable independently of later route state. See the kit README for generation and later-ticket ownership.

## Iteration

Initial rendered captures exposed overly pale ground/materials and fine-grain aliasing. Material generation now converts authored sRGB colours to linear values like the truck generator; the ground uses dark linear asphalt values with subtle dust and derivative-faded grain. Roof seams now follow both roof slopes. Dense salvage rows sit beyond the perimeter, and their collision plus the exterior ground skirt support deliberate fence climbing. Final art captures use shipping 1280×720 and 4×MSAA rather than the fixture's 800×600/no-AA defaults; capture settings are restored afterward.

The first performance capture had a wrong-arity `get_render_info` call, corrected before complete validation. A later intermittent existing proportion assertion failed despite unchanged learner code. Tagged diagnostic output first passed at scale 1.000001–1.000002, then the original strict assertion reproduced at 1.000010–1.000012 with parent scale 0.999999–1.0 (`08a-scale-red.log`). These are approximately 12 parts per million from world/local rotation decomposition, not visible compression. The fixture now uses an explicit 0.1% per-axis tolerance and retains exact values on failure; it still rejects meaningful body scaling, including the previous 0.35 compressed pose. No learner, pose, networking or runtime workaround was introduced. Temporary diagnostic prints were removed.
