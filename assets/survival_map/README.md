# Rift quarry and navigator's field book

Original Blender-authored geometry, generated by `source/build_map.py`; no downloaded assets. Editable assembled source is `source/quarry.blend`, and the book is `source/field_book.blend`. Godot loads the four exported GLBs, so running the game does not require Blender. The source directory is excluded from Godot import.

Regenerate with Blender 5.2:

```powershell
& 'C:\Program Files\Blender Foundation\Blender 5.2\blender.exe' --background --python assets/survival_map/source/build_map.py
```

The generator uses Godot metres (Y up, travel toward negative Z), converting to Blender coordinates for glTF export. The source scene assembles intact bridges for editing; runtime selects intact or physically broken spans at each of the three crossings. Distinct landmarks are The Cut, Pump Works, and High Quarry. Rounded asphalt aprons use matching convex collision; bridge support remains explicit and scenery has mesh collision. Falls below the existing lethal threshold still lose the attempt.

The private book has cloth covers, a rounded spine, layered paper edges, brass corners and a ribbon. A separate local 3D viewport supplies readable page lettering and an animated turning leaf. Q/E, arrow keys or Page Up/Down turn pages; Tab lowers or raises the book. E is consumed while reading so it cannot also leave the navigator seat. Contents and three landmark entries must be searched manually; course progress does not select a page. Other seats receive no book view. A retry opens the contents and cancels any turn in progress.

Verify with `tests/verify_navigation_book.gd -- --rehearsal`, `tests/verify_survival_scene.gd`, and `tests/verify_launch_network.gd -- --survival`. Capture real gameplay views using `tests/capture_modeled_map.gd -- --rehearsal`.
